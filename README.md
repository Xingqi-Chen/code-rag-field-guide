# Code RAG Field Guide｜代码检索与图的中文实测指南

把代码仓库想成图书馆：**关键词检索是查目录，语义检索是按意思找书，代码图是标出“谁调用谁”的地图。** RAG 则先找材料，再让模型据此回答。地图能帮你沿关系找下一本书，但路标缺失或走错路，也会挤掉本来有用的材料。

这份研究回答：**Graph RAG 对代码何时有价值，何时不值得？** 它结合截至 **2026-10-12** 的一手资料，以及在 Mac mini 上实际运行的可复现实验。

**先读：[完整中文报告](docs/report.md)** · [来源与版本](docs/sources.md) · [逐题证据](benchmark/questions.md) · [复现命令](docs/reproduce.md)

## 一页核心结论

1. **有条件的价值。** 调用、引用和依赖图适合补充跨文件调查；实体抽取与社区摘要更适合文档全局归纳。Microsoft GraphRAG、AST、调用图和图预训练不是同一种方案。[区别与研究证据](docs/report.md)
2. **先建立强搜索基线。** 保留能找精确名字的关键词／符号搜索，实测语义检索、融合和重排是否有帮助；再针对漏掉的关系加图。Agent 可以多轮调用这些工具，长上下文只是容纳资料的空间。[方案与落地建议](docs/report.md)
3. **本次主预算没有“加图必胜”。** 两个 Python 仓库、26道正例，在每题最多8块的预算下，图扩展的证据覆盖比混合检索低 **4.81个百分点**；逐题0胜、23平、3负。4块和12块预算下方向反转，说明预算与选择策略会改变结论。[全部结果](results/summary.md)
4. **适合尝试图：** 经常追调用链、变更影响或跨模块证据，且能维护可信的符号索引。**暂缓重型图：** 问题主要是找名字、仓库很小、动态关系无法可靠解析、没有固定预算评估，或维护投入超过实测收益。
5. **不能从这里推导回答准确率。** 本实验只测“找到了哪些证据”，没运行回答模型、完整实体 GraphRAG、reranker 或多轮 agent，也不代表商业产品排名。题目由研究代理构造和静态核对，没有外部人类标注员；样本小且集中于英文查询。[限制与审计](docs/audit.md)

## 实际测到了什么

主预算：同一语料、同一 AST 感知分块，每题最多8块／1920个 MiniLM tokenizer token。数字为26个正例的宏平均，4个负例另列。

|方法|关键证据覆盖|相关块 Recall@8|MRR@8|平均上下文 token|
|---|---:|---:|---:|---:|
|BM25，保留并拆分标识符|54.5%|56.1%|0.503|1289|
|本地 MiniLM 真实语义向量|74.0%|73.1%|0.581|1314|
|BM25 + 向量，RRF融合|67.3%|67.9%|0.568|1379|
|混合检索 + 静态图扩展|62.5%|63.5%|0.556|1357|
|混合检索 + 随机扩展对照|53.5%|55.1%|0.548|1118|

模型为 `sentence-transformers/all-MiniLM-L6-v2`，384维；[固定revision](NOTICE.md)为 `1110a243fdf4…`。它是小型通用英文模型，**不是代码专用最优模型**。自然语言题型、注释丰富的语料和固定等权融合会影响相对成绩。图方法保留前4个种子、用4个名额补一跳邻居；随机对照使用相同槽数。实际token数不同，因此这里只控制共同上限，未声称长度完全相等。主预算图减混合检索的配对bootstrap描述区间为 **[-10.58, 0.00] 个百分点**；这不是随机抽样的行业置信区间。

一个具体失败：Click 的“文件参数何时真正打开文件”需要连接类型转换与惰性文件打开操作。主预算图扩展从原本找到的一半证据退到零；可解析的局部关系没有补上实例行为，又挤掉了有用的排名结果。[失败分析](docs/report.md)、[C06证据](benchmark/questions.md#c06--cross_file)

## 实验与复现

- **机器：** Apple M4，10核CPU，16 GiB内存，macOS 26.4.1；本地CPU推理、4线程，无付费API。
- **语料：** Requests v2.32.3、Click 8.1.8，固定commit，共34个源文件、15,847行、1,280块；[许可证和归因](NOTICE.md)。
- **设计：** 30道冻结题、70个可检查行锚，涵盖定位、跨文件、影响分析、概念与负例；[冻结协议](benchmark/protocol.md)。
- **交付：** [450条逐题排名](results/raw.jsonl)、[环境／索引成本](results/environment.json)、[真实日志](logs/experiment.log)、[审计更正记录](docs/audit.md)。源码、权重和缓存不入库。

无需模型、无需网络即可复算已公开结果：

```bash
python3 scripts/aggregate.py --check
python3 scripts/validate.py
```
