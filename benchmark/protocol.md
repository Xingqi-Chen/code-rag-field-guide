# 预注册协议 v1

冻结时间由 Git 提交记录与 `freeze.json` 记录。冻结前仅审阅源文件和标注；没有运行任何题目的检索排名。此小样本是作者构造、可人工检查的教学基准，不是第三方双盲标注，也没有声称人工专家审定。

## 范围与题目

- Requests v2.32.3 与 Click 8.1.8，确切 commit、源目录和许可证见 corpora.json。只索引源目录的 `.py`；不索引 tests、docs、问题、答案、报告或题目标注。不运行语料代码。
- 每库15题：4定位、4跨文件、3影响分析、2概念、2负例。共26正例、4负例、70个行锚。影响分析仅评估题目列出的证据路径，不声称找到所有受影响位置。
- `query` 英文是唯一检索输入；中文只供读者理解。选择英文因语料注释与小型模型以英文为主；不能外推中文查询质量。
- 先写自然问题，再静态检查证据；没有用任何检索排名挑题或增加标注。题目包含现实问题中的技术术语，但不由目标块自动生成同义词/答案关键词。
- 每条证据是指定 commit 的路径+关键行+行哈希+原创释义，所有锚可点击源文件人工复核。行锚衡量关键证据触达，不代表上下文足以完整回答。未标注块叫“未标注上下文”，不保证其语义无关。

## 固定检索设计

共同语料与 AST 感知分块：每行归属最内层函数、类或模块；连续行段按固定 tokenizer 不超过240 token切分，不重叠，保留文件/符号前缀。超长行若存在采用小片段切分并记录。正文、注释与docstring都进入索引。

1. **BM25**：Okapi k1=1.5,b=0.75，标识符原词+snake/camel拆词、英文常见停用词过滤；查询同样处理。不加入已知证据词、不调参。
2. **Dense**：sentence-transformers/all-MiniLM-L6-v2，固定 revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`，22M级通用英文句向量，384维，CPU float32、L2归一化、点积。不是代码专用最优模型，也不是 TF-IDF。
3. **Hybrid**：两个完整排名等权 RRF，常数60；只在指定库内检索。
4. **Hybrid+graph**：保留 hybrid 前一半结果，再从其一跳结构邻居中按 hybrid 分数取后一半；不足则用 hybrid 余项填满。结构边来自同符号连续块及保守静态可解析调用，含反向边用于调用者查找；不把猜测的同名方法当确定调用。图允许缺失动态调用。
5. **Hybrid+random**：同样的前一半种子、相同数量扩展槽，从该库非种子块随机抽取，按 hybrid 分数排序；随机种子1729与稳定题目ID派生。用于判断效果是否仅来自额外内容；hybrid 本身则是同预算纯排名对照。

主预算8块，每块<=240模型token，总上限1920（含前缀，不含分隔符）。敏感性预算4/12块，上限960/2880；图/随机扩展各占一半，不按题型特判。不同方法实际token数仍可能不同，必须报告。以相同上限控制而非假装实际长度相等。预算不是生成模型的token计量。

仅当工程成本合理才另加 reranker/agentic；若添加必须在看到结果前补充冻结协议。不将静态graph扩展命名agentic。本轮不运行回答模型/实体抽取LLM/长上下文生成，不报告回答准确率。

## 指标与统计

- 正例宏平均：相关块 Recall@k、MRR@k、binary nDCG@k、关键行证据覆盖率、所有标注证据覆盖比例、未标注块比例、实际上下文token。
- 相关块定义：至少覆盖一个冻结关键行。一个证据可能与多个证据同处一块；块Recall与证据覆盖因此不同。
- 负例单列：这些固定top-k检索器没有拒答阈值，记录每题返回数量/分数，预期总会返回上下文；不能把空qrels记作0后混入正例平均，不能声称具备拒答能力。
- 按库/题型分组。对主预算图减hybrid的逐题证据覆盖差做10,000次配对bootstrap（seed1729）95%百分位区间；题目非随机抽样、样本关联，区间仅描述本题集，不代表行业泛化或正式显著性论证。
- 时延：CPU、线程数固定4；query embedding预热一次；逐题3次取中位数，分开记录embedding、BM25、dense点积、fusion、graph、random，方法时延为所需阶段之和。非并发交互实测，非服务p99/SLA。
- 索引：报告切块/图/BM25/vector编码时间、序列化索引字节；模型下载和加载单列；进程最大RSS为整轮联合索引/检索峰值，不能冒充单方法独立峰值。不测更新重建成本则明确未测。
- 逐题排名、指标、聚合脚本全公开；向量、源码、权重与缓存不提交。排名公布块元数据与固定源码链接，避免复制大量第三方代码。

## 防止事后选择

首次完整运行后不改题目、证据、超参数或边算法以改善成绩。若发现实现bug，保留失败记录、说明与修复提交，整体重跑，不只重跑“好看”的题。图胜负均报告，至少解释一条退化/失败案例。对动态回调、继承、别名、外部库与反射造成的图不完备明确披露。
