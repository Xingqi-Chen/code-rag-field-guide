 This document covers some of the more advanced features of Requests.
 
+Case-Insensitive Dictionaries
+-----------------------------
+
+Requests' ``CaseInsensitiveDict`` supports mapping union operators. Both
+operands must be mappings:
+
+.. code-block:: python
+
+    combined = headers | overrides
+    combined = overrides | headers
+    headers |= overrides
+
+The non-mutating ``|`` operation returns a new ``CaseInsensitiveDict`` and
+does not modify either operand. The in-place ``|=`` operation returns and
+updates its left-hand operand. When keys differ only by case, the
+right-hand value and spelling take precedence.
+
